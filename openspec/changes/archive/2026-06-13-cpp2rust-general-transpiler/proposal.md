## Why

The rusty-v8 transpiler is V8-specific: its fallback path emits `todo!()` (code that doesn't compile), its prelude is hardwired to V8 types, and its macro/type handling is non-portable. No mature open-source C++ → Rust transpiler exists — c2rust handles C only, and every major project chose FFI interop over true transpilation. This is the gap. We build `cpp2rust`: a general-purpose C++ to Rust transpiler with a plugin system, using V8's bigint module as the first benchmarkable target.

## What Changes

- **New tool**: `cpp2rust/` — a standalone, plugin-driven C++ → Rust transpiler replacing the V8-specific `transpiler/` directory
- **Phase 1 (always-compiles) emitter**: every C++ construct maps to unsafe Rust that compiles; `todo!()` is completely eliminated as a fallback
- **Pattern library**: declarative YAML mapping of known C++ idioms (bit_cast, make_unique, DCHECK, etc.) to Rust equivalents
- **Plugin system**: per-codebase config (YAML + Python plugin) for type mappings, macro mappings, prelude stubs, and module layout
- **V8 plugin**: ports existing V8-specific logic from `transpiler/mapper/v8_mapper.py` and `module_emitter.py` into a self-contained plugin
- **Dependency wirer**: auto-generates Cargo.toml inter-crate dependencies from the C++ `#include` graph — fixes the dominant E0425 error class
- **Template resolver**: monomorphizes C++ templates using Clang's instantiation records; plugin-annotated types preserved as Rust generics
- **Ownership analysis pass** (Phase 2): classifies raw pointer uses (owning/borrow/array/aliased) and rewrites to `Box<T>` / `&T` / `Vec<T>` where provable
- **V8 bigint benchmark**: first end-to-end deliverable — `v8-bigint` crate compiles 100% in pure Rust with matching bigint arithmetic results and a perf comparison vs C++

## Capabilities

### New Capabilities

- `cpp-extractor`: Generic C++ AST extraction via libclang — parses any C++ codebase given compile_commands.json, emits cached ExtractedFile JSON
- `ir-model`: Language-neutral intermediate representation covering all C++ constructs (structs, enums, templates, inheritance, operator overloads, lambdas)
- `phase1-emitter`: Unsafe Rust emitter with always-compiles guarantee — every unrecognized construct emits `Default::default()` + `// UNTRANSLATED` comment rather than `todo!()`
- `pattern-library`: Declarative YAML pattern matching for known C++ → Rust idioms; applied before the raw fallback
- `plugin-system`: Plugin interface allowing per-codebase type mappings, macro mappings, prelude injection, and module layout configuration
- `v8-plugin`: V8-specific plugin implementing Handle<T>, digit_t, DCHECK/CHECK, and V8 module layout
- `dependency-wirer`: Analyzes the #include graph across all extracted files and emits correct Cargo.toml [dependencies] sections per crate
- `template-resolver`: Enumerates Clang template instantiations and monomorphizes to concrete Rust types; respects plugin-annotated generic types
- `ownership-analysis`: Phase 2 static analysis classifying pointer uses and rewriting to safe Rust types where ownership is provable
- `v8-bigint-benchmark`: Benchmark harness comparing v8-bigint Rust crate vs C++ V8 bigint on Multiply, Divide, Add, and ToString operations

## Impact

- `transpiler/` directory: superseded by `cpp2rust/`; kept intact as reference until benchmark is complete
- `output/transpiled/`: regenerated by the new tool; existing output is compatible as a baseline
- No external API changes (this is a standalone CLI tool)
- Dependencies added: `PyYAML` for pattern library parsing; no new Rust dependencies
- V8 codebase (`codebase/`): read-only, no changes
